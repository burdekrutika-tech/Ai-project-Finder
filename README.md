# 🤖 AI Project Finder

AI Project Finder is an AI-powered web application that helps students discover suitable college project ideas based on their skills, interests, preferred technology, experience level, difficulty, and project type.

Instead of spending hours searching for project topics, students can enter their preferences and get personalized project recommendations using AI.

## ✨ Features

- 🤖 AI-powered project recommendations
- 🎯 Personalized project matching
- 💡 Multiple unique project ideas
- 📊 AI-generated match scores
- 📝 Project-specific descriptions
- ✨ Detailed project features
- 🎯 Project objectives
- 🧩 Project modules
- 🛠️ Development steps
- 🚀 Future scope
- 🗂️ Project categories
- 📱 Responsive web design
- 📩 Contact page
- 🔐 Secure API key configuration using environment variables

## 🛠️ Technologies Used

- Python
- Flask
- HTML5
- CSS3
- JavaScript
- Groq API
- OpenAI GPT-OSS-20B model
- Jinja2
- python-dotenv

## ⚙️ How It Works

1. Student opens AI Project Finder.
2. Student selects their preferred domain.
3. Student selects technology.
4. Student selects experience level.
5. Student selects project difficulty.
6. Student selects their interest.
7. Student selects project type.
8. AI analyzes the preferences.
9. AI generates suitable project ideas.
10. Student can view detailed information about any project.
